01 Project Overview
What This System Does

Build a full-stack AI-powered co-pilot that helps early-stage founders analyze, structure, and refine their startup ideas through a stateful, multi-agent reasoning pipeline. The system does not make promises — it produces structured, data-grounded insights that help founders make better decisions.

Unlike simple chatbots or generic LLM wrappers, this system uses LangGraph to orchestrate a directed acyclic graph of specialized agents, each responsible for one analytical layer of the startup analysis process.

Core Promise: "Here are insights, risks, and structured recommendations to help you make better decisions" — not "your idea will succeed." This distinction makes the system academically honest, practically useful, and demonstrates real understanding of responsible AI deployment.

02 LangGraph Agent Pipeline
Stateful Workflow Graph
IN
Idea Input Node
Raw founder input (text, voice, or structured form). Feeds into the shared LangGraph state object that persists across all downstream agents.
→ raw_idea_state
01
Context Builder Agent
Transforms vague or informal idea descriptions into a structured concept schema. Extracts target users, core problem statement, and the proposed solution. Prompts the founder with clarifying questions if critical fields are missing.
→ structured_idea_schema
02
Market Insight Agent
Retrieves and synthesizes industry context, demand indicators, and macro-level trends relevant to the idea's domain. Uses RAG over a curated knowledge base of industry reports, Crunchbase summaries, and market data.
→ market_context_block
03
Competitor Mapping Agent
Identifies existing solutions and players in the space. Maps positioning opportunities and differentiators. Uses web search tools + vector similarity over a startup database to find both direct and indirect competitors.
→ competitor_landscape
04
Business Structuring Agent
Suggests revenue models, value propositions, and a lean canvas framework tailored to the idea. Provides multiple business model options with trade-off analysis (e.g., SaaS vs. marketplace vs. freemium).
→ lean_canvas_draft
05
Risk & Assumption Analyzer
The system's honesty engine. Surfaces key uncertainties, execution risks, critical assumptions, and early-stage blind spots. Assigns a qualitative confidence tier (High / Medium / Low) to each insight with an explanation.
→ risk_matrix + assumptions
06
Pitch & Communication Agent
Synthesizes all prior agent outputs into a polished communication layer: a clear problem statement, a compelling value proposition, and a 30–60 second pitch script tailored to the founder's target audience.
→ pitch_draft
OUT
Final Report Assembler
Merges all agent outputs into three downloadable artifacts: Startup Insight Report, MVP Planning Guide, and Pitch Draft. Renders in-app and exports to PDF/Markdown.
→ 3 downloadable artifacts

06 Generation Prompt
// master prompt — paste this to generate the full application
Build a full-stack, production-grade AI-Assisted Startup Insight & Planning System using LangChain and LangGraph. This is a multi-agent reasoning pipeline — not a simple chatbot — that takes a raw startup idea as input and produces three structured output artifacts: a Startup Insight Report, an MVP Planning Guide, and a Pitch Draft.

Architecture requirements:
Implement a LangGraph StateGraph with a shared TypedDict state object that flows through 6 sequential agent nodes: context_builder → market_insight → competitor_mapper → business_structurer → risk_analyzer → pitch_writer. Each node must be a dedicated Python class with its own LangChain chain, system prompt, and output schema (Pydantic models). Use conditional_edge routing to allow the context builder to loop back if the idea is too vague (missing target_user, problem, or solution fields). Add a human-in-the-loop interrupt after the context builder so founders can confirm or correct the structured interpretation before analysis begins.

Agent-by-agent specifications:
(1) Context Builder — use GPT-4o with structured output and a Pydantic schema with fields: idea_title, problem_statement, target_users, proposed_solution, industry_vertical, geography. If any required field is null, emit a clarifying question and loop. (2) Market Insight Agent — use RAG over a Chroma vector store seeded with 50+ industry reports. Return 3–5 grounded insights with source tags. Prefix all outputs with a confidence tier [HIGH / MED / LOW]. (3) Competitor Mapper — call Tavily search tool with the idea's industry_vertical + problem keywords. Parse results into a competitor table: name, stage, differentiator, threat_level. Suggest two positioning gaps. (4) Business Structurer — populate a full 9-block Lean Canvas JSON object. Offer two alternative revenue model paths with a short trade-off paragraph each. (5) Risk Analyzer — generate a structured risk_matrix list: each item has risk_type, description, severity (1–5), and recommended_experiment to de-risk. Also produce an assumption_log with 5–7 critical assumptions ranked by uncertainty. (6) Pitch Writer — synthesize all prior state into: one_liner (max 20 words), spoken_script_30s, spoken_script_60s, slide_outline (5 slides with titles + bullet points), and audience_adaptation_notes for investor / customer / hackathon contexts.

Backend API: FastAPI with a /analyze POST endpoint that accepts idea text and streams agent progress via Server-Sent Events. Each agent emits a progress_event with stage, status, and partial output as it completes. Store completed analyses in PostgreSQL with a UUID session ID. Expose a /history/{session_id} GET endpoint to retrieve past analyses. Add a /refine POST endpoint that loads a prior LangGraph checkpoint and re-runs with updated founder input.

Frontend UI: React 18 + TypeScript single-page application. The main screen has three panels: (A) an idea input form with a progress tracker showing the LangGraph pipeline as a live animated node graph (use React Flow — nodes turn green as agents complete), (B) a tabbed results panel with one tab per artifact (Insight Report / MVP Guide / Pitch Draft), and (C) an iteration sidebar where founders can refine specific sections and re-trigger individual agents. Stream agent output in real-time using EventSource. Render the Lean Canvas as an interactive 9-block grid. Render the risk matrix as a 2D scatter plot (severity × likelihood) using Recharts. Export all three artifacts to PDF using react-pdf.

Memory & iteration: Use LangGraph's built-in SqliteSaver checkpointer (dev) or PostgresSaver (prod) to persist graph state by session UUID. When a founder submits a refined idea, load the checkpoint, update the state, and resume from the first affected node — do not re-run agents whose upstream inputs have not changed. Embed completed idea schemas in the vector store so the system can surface semantically similar past analyses.

Extra features to implement: (1) A LangGraph workflow visualizer component in the UI that renders the actual graph topology (nodes, edges, conditional branches) as a React Flow diagram — not a static image, but a live graph that highlights the currently executing node in real time. (2) A confidence score display on every insight: a colored badge (green / amber / red) with an explanation tooltip showing which data sources grounded the claim. (3) A SWOT analysis section in the Insight Report tab, rendered as a 2×2 grid with color-coded quadrants. (4) A comparison mode that loads two past analyses side-by-side for founders iterating on idea pivots.

Code quality requirements: Full type annotations throughout Python and TypeScript. Async FastAPI endpoints. Pydantic v2 schemas for all agent outputs. Environment-variable-based configuration (no hardcoded keys). Docker Compose setup with services for api, frontend, postgres, redis, and chromadb. A comprehensive README.md with architecture diagram, setup instructions, and example curl commands. Unit tests for each agent node using pytest and langchain's testing utilities. LangSmith tracing enabled in production for full pipeline observability.

Design philosophy: The system must never claim to validate or guarantee startup success. Every output must be framed as "structured insight to support decision-making." This framing should be visible in the UI (a persistent disclaimer banner), in agent system prompts, and in the generated reports themselves. The goal is a tool that impresses with its depth and honesty — not one that tells founders what they want to hear.
07 Standout Features
Live graph visualization — React Flow renders the LangGraph topology in real time, highlighting the active node as agents execute
Confidence tiers on every insight — HIGH / MED / LOW badges with source attribution and explanation tooltips throughout the report
Human-in-the-loop checkpoint — founders confirm the structured idea interpretation before the analysis pipeline runs
Selective re-run on refinement — LangGraph checkpointing means only affected downstream nodes re-execute when input changes
Idea memory via vector DB — past analyses are embedded and surfaced when a new idea is semantically similar to a prior one
Side-by-side pivot comparison — load two analysis sessions and compare outputs column-by-column for structured pivot reasoning
Audience-adaptive pitch generation — the pitch agent adapts tone and emphasis for investor, customer, or hackathon judge audiences
LangSmith observability — full pipeline tracing, latency breakdown per agent, and token usage dashboards in production
